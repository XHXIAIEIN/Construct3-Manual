The `IBillboardBehaviorInstance` interface derives from [IBehaviorInstance](../../../scripting/scripting-reference/object-interfaces/ibehaviorinstance.md) to add APIs specific to the [Billboard behavior](../../../behavior-reference/billboard.md).

## Billboard behavior APIs

**offsetX**  
Set or get the additional 3D rotation in radians to apply around the X, Y and Z axes after orienting the object directly towards the camera.

**offsetY**  
Set or get the additional 3D rotation in radians to apply around the X, Y and Z axes after orienting the object directly towards the camera.

**offsetZ**  
Set or get the additional 3D rotation in radians to apply around the X, Y and Z axes after orienting the object directly towards the camera.

**isEnabled**  
A boolean indicating if the behavior is enabled. If disabled, the behavior no longer has any effect on the object.
