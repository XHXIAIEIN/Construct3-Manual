## Example Hosted Message URL

```json
{
  "language": {
    "iso": "EN",
    "englishName": "English"
  },
  "url": "awpxC"
}
```

## Object Properties

**language** [`Language`](../../common-objects/language.md)  
The language this URL is served in.

**url** `string`  
The URL to the hosted broadcast message.
