## Actions

**Award XP**  
Awards a specified amount of XP to the player.

**Deduct XP**  
Deducts a specified amount of XP to the player.

**Award Achievement**  
Awards or progresses an achievement for a player.  For progressive achievements, a progressive value must be specified.

**Remove Achievement**  
Unawards or un-progresses an achievement for a player.  For progressive achievements, a progressive value to deduct must be specified.

**Publish Discord Message**  
Publish a message to a Discord webhook
